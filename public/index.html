⚡ Want a free, private proxy that never gets blocked? (1-Min Cloudflare Worker)

1. Go to workers.cloudflare.com (Free: 100,000 req/day).

2. Create a Worker and paste this code:

export default {
  async fetch(req) {
    const url = new URL(req.url).searchParams.get("url");
    if (!url) return new Response("Missing url", { status: 400 });
    const res = await fetch(url, { headers: { "User-Agent": "Mozilla/5.0", "Accept": "application/json" } });
    const cors = new Headers(res.headers);
    cors.set("Access-Control-Allow-Origin", "*");
    return new Response(res.body, { status: res.status, headers: cors });
  }
};

3. Deploy and paste your worker URL above: https://<worker>.workers.dev/?url=
